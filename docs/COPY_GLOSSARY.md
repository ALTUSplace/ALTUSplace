# Glossary — المصطلحات الموحدة (ALTUSplace)

كمرجع واحد لفريق التحرير والمطورين. الهدف: لغة عربية فصحى واضحة (MSA) في واجهات
المنصة، مع السماح باللهجة المغربية الدارجة في العناوين التسويقية فقط إذا كانت
مستخدمة أصلاً. التاريخ: 2026-09-18 (المراجعة الأولى).

## المبادئ العامة

1. **واحدة لكل مفهوم**: كل مصطلح تقني/تجاري له ترجمة واحدة فقط، تُطبق في كل الصفحات.
2. **الكراء لا التأجير**: المصطلح الرسمي للمنتج هو **"الكراء"** (وفق الاستعمال
   المغربي وأكثر الكلمات بحثاً: «كراء السيارات في المغرب»). كلمة "تأجير" هي فعل
   مقدّم الخدمة فقط، ولا تُستعمل في عناوين ونسخ الواجهة. "الإيجار" تُستعمل حصراً
   في السياق القانوني/العقدي.
3. **الأرقام اللاتينية** (0-9) في المدخلات والأسعار، مع «درهم / MAD» كوحدة.
4. **همزة و تاء مربوطة**: مراجعة أ/إ/ا في كل كلمة (مثال: "مرفوض" وليست "مرفوع").

## جدول المصطلحات

| المصطلح (FR/EN) | الترجمة الموحدة | ملاحظات / سبب الاختيار |
|---|---|---|
| Rental (noun, product) | **الكراء** (مدة الكراء، كراء السيارات، باقات الكراء) | التوافق مع البحث المغربي «كراء السيارات» وإجماع نسخ الواجهة الحالية |
| Leasing / to rent (verb) | تأجير (فقط كفعل/عملية) | لا يُستعمل في العناوين الرئيسية |
| Rent (contractual / lease) | الإيجار (سياق عقدي/قانوني فقط) | TermsOfService؛ عدم الخلط بين المنتج والعقد |
| Property / Real estate | **عقار / العقارات** | موحّدة في كل الشاشات |
| Car rental | **كراء السيارات** | الكلمة المفتاحية الرئيسية (SEO) |
| Booking | حجز / الحجز | «حجوزاتي»، «طلبات الحجز» |
| Listing / Ad | **إعلان / الإعلانات** | «عروض» في التسويق تُترَك أحياناً، الأساس إعلان |
| Partner / Agency | شريك / وكالة | «فضاء الشركاء» للواجهة العامة |
| Provider | مزوّد الخدمة | placeholder موحّد |
| Availability | التوفر / غير متاح | حالة الإعلان |
| Review (verified) | مراجعة موثقة / تقييم | «تقييم موثق» وليس «انطباع» |
| Deposit / Caution | تأمين / ضمانة مالية | في سياق الحجز الدفعات يُستعمل «تأمين الحجز» |
| Monthly rent | كراء شهري | يخص العقارات |
| Daily rate | سعر يومي | يخص السيارات |
| Pick-up / Drop-off | الاستلام / الاسترجاع | موحّد في حقلَي التاريخ |

## افتحاحات إملائية موحَّدة
- «الوصول مرفوض» (وليس مرفوع).
- «تذكرة الوصول» بدل «Voucher» في نصوص العربية.
- بدون إقحام الإنجليزية بين قوسين في النسخ العربية (تُحذف «(Resident)» وغيره)،
  ما عدا الأسماء التجارية/التقنية المتفق عليها: ALTUSplace، CMI، MAD، QR، iCal،
  Google Maps، TVA، RC، CIN.

## قاعدة للكود
- كل السلاسل الظاهرة للمستخدم تمر عبر `t()` أو خريطة عربية. أي حالة backend
  (status) لا بد أن تمر عبر خريطة ترجمة (`statusLabel` / `PaymentStatusBadge`)
  وألا تُعرض خام.
- عند إضافة نص جديد: اكتبه بالعربية أولاً ثم أضف fr/en بنفس المفتاح.
